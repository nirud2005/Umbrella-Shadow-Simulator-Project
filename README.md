# umbrella-shadow

เว็บจำลองตำแหน่งเงาของร่มสนาม (ร่มราบแนวระดับ) ตามตำแหน่งดวงอาทิตย์ — กรอกละติจูด/ลองจิจูด วันที่ เวลา รัศมีและความสูงร่ม แล้วดูเงาแบบภาพนิ่งหรือ Animation ตลอดวัน

ใช้สูตรดาราศาสตร์มาตรฐาน (เดคลิเนชัน, มุมชั่วโมง, สมการเวลา, มุมเงย/มุมทิศ) เวลานาฬิกาอ้างอิงตามเขตเวลาของสถานที่ที่เลือก

เดคลิเนชัน (δ) คำนวณจากตำแหน่งจริงของดวงอาทิตย์ (ลองจิจูดสุริยวิถีแบบ Meeus หนึ่งค่าต่อวัน ณ เที่ยงท้องถิ่น) วันไร้เงาจึงตรงกับของจริงทั้งวันและเวลา (กรุงเทพฯ ปี 2569: 27 เม.ย. 12:16 น. และ 16 ส.ค. 12:22 น.)

มีลูกโลกแสดงจุดที่ดวงอาทิตย์อยู่เหนือศีรษะ เส้นแบ่งกลางวัน/กลางคืน และเส้นทางของดวงอาทิตย์ตลอดวัน (ใช้ d3-geo + world-atlas จาก CDN)

## สถานที่และ Animation
- เลือกสถานที่จาก 77 จังหวัดของไทย (พิกัดตัวเมือง) หรือกด "ตำแหน่งของฉัน" หรือกรอกละติจูด/ลองจิจูดเองก็ได้
- ปุ่มลัดวัน: วสันตวิษุวัต · ครีษมายัน · ศารทวิษุวัต · เหมายัน (คำนวณวันที่จริงตามปีและเขตเวลาที่เลือก)
- กรอกรัศมีร่ม R และความสูงร่ม h ได้เองที่การ์ด "ขนาดร่ม" (กราฟและผลลัพธ์เปลี่ยนทันที)
- เวลาพระอาทิตย์ขึ้น–ตกใช้นิยามมาตรฐานเดียวกับแอปสภาพอากาศ (ขอบบนของดวงอาทิตย์พ้นขอบฟ้า + การหักเหแสง คือมุมเงยศูนย์กลาง −0.833°) ต่างจากแอปไม่เกิน 1–2 นาที
- Animation: **ลูกโลก** และ **กราฟเงา** เล่นพร้อมกันตั้งแต่พระอาทิตย์ขึ้นถึงตก (แสดงเวลาขึ้น–ตกในหน้า) เลือกความเร็วได้ 0.5× / 1× / 2× / 4×
- กดเล่นแล้วจะเปิด **หน้าต่างดู Animation**: ลูกโลกอยู่ซ้าย กราฟเงาอยู่ขวา มีแถบเลื่อนเวลา ปุ่มหยุด/เล่นอีกครั้ง และความเร็วในหน้าต่างเดียวกัน กราฟวาดรอยทางของเงาที่ผ่านมา เล่นจบแล้วค้างที่เฟรมสุดท้าย (ตอนตกดินแสดงเงาตำแหน่งสุดท้ายก่อนตก) ปิดหน้าต่างได้ด้วยปุ่มหรือ Esc
- กราฟเงาแสดงพิกัดฉาก (x, y) และพิกัดเชิงขั้ว (d, ψ) ในรูป

## ใช้งาน
เปิดผ่าน GitHub Pages หรือเปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

## ทดสอบ
`node test.js` เทียบสูตรส่วนอื่นกับค่าที่คำนวณจากโปรแกรม Python ต้นฉบับ (`ref.json`, 200 กรณี ใช้สมการ (1) ของใบงานเป็น δ) และตรวจว่า δ ตามจริงให้วันไร้เงาของกรุงเทพฯ ปี 2569 ตรงกับของจริง
